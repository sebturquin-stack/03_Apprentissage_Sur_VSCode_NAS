## 🎯 Objectif du dossier

Ce dossier contient l’ensemble des modèles de documents utilisés dans le QG 2056.
Ils permettent de créer rapidement des documents cohérents, professionnels et faciles à maintenir.

---

│

├── C_PROCEDURES/
├── D_SCHEMAS/
├── E_DOSSIERS_COMPLETS/

Chaque sous-dossier contient des modèles `.md` prêts à l’emploi.

---

## 🗂️ Contenu des catégories

### A — README

Modèles pour structurer les README de tous les dossiers du QG.

### B — Fiches Techniques

Modèles pour documenter les appareils, services et composants réseau.

### C — Procédures

Modèles pour les actions techniques, diagnostics, incidents et checklists.

### D — Schémas

Modèles Mermaid et ASCII pour représenter l’architecture réseau.

### E — Dossiers Complets

Squelettes complets pour créer des modules entiers du QG.

### F — Modèles Personnalisés

Notes techniques, rapports, documents transverses.

---

## 🧠 Comment utiliser les modèles

1. Ouvrir le modèle souhaité.
2. Copier son contenu.
3. Le coller dans un nouveau fichier dans le dossier approprié.
4. Remplir les champs `${VARIABLE}`.
5. Sauvegarder.

---

## 🔧 Intégration avec VSCode

Les modèles sont compatibles avec :

- les snippets personnalisés (module 3.6.1)
- l’extension Markdown Table Prettifier
- l’aperçu Markdown (`Ctrl + Shift + V`)
- les schémas Mermaid
