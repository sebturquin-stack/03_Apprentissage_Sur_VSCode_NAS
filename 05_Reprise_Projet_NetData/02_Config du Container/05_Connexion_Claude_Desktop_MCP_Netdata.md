🚀 3️⃣ Ajouter ton MCP dans la config de Claude Desktop
Claude Desktop utilise un fichier de configuration MCP.
Sur Linux Mint, il se trouve dans :

Code
~/.config/Claude/mcp.json
S’il n’existe pas, tu le crées.

Mets dedans exactement ceci :
json
{
  "mcpServers": {
    "netdata-mcp": {
      "command": "docker",
      "args": [
        "exec",
        "-i",
        "01_Node-20_MCP",
        "node",
        "/app/netdata-mcp.js"
      ]
    }
  }
}
Ligne par ligne :

netdata-mcp → nom de ton serveur MCP

docker → Claude va lancer Docker

exec -i → garde STDIN ouvert (obligatoire pour MCP)

01_Node-20_MCP → ton conteneur

node /app/netdata-mcp.js → ton script MCP

C’est propre, simple, efficace.
